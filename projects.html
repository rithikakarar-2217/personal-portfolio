XOXO Tic-Tac-Toe Web Application

A clean, turn-based two-player browser game engineered to master state tracking and responsive DOM interactions.

› 01. The Problem or Idea
How can a web browser maintain an internal representation of a 3x3 game board, alternate turns reliably between two players (Player X and Player O), prevent accidental overwriting of marked cells, and calculate winner configurations across 8 distinct axes without external libraries?
› 02. The Engineering Approach
I modeled the board as a 9-element array ['','','','','','','','','']. I defined an immutable matrix of winning combinations (3 rows, 3 columns, and 2 diagonals). For every click event, the script verifies if the tile is unoccupied, updates the state array with the current player's token, renders the symbol, checks if a win pattern is fulfilled, and detects a tie if no empty cells remain.
› 03. Actual Implemented Functionality
  • Interactive 3x3 clickable grid with keyboard and mouse support.
  • Automatic turn switching between Player X (Electric Lime) and Player O (Cyan).
  • Real-time win verification highlighting the 3 winning tiles.
  • Draw / Cat's game detection when 9 turns elapse without a winner.
  • Instant reset button to replay without page reload.
› 04. What I Learned
This project cemented my understanding of how user actions generate asynchronous events in JavaScript. I learned to separate internal application state (the JavaScript array) from the visual presentation layer (the HTML DOM). It also taught me edge-case testing, such as making sure players cannot click on an already-claimed square.
